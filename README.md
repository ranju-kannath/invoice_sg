Singapore Compliance & InvoiceNow (PEPPOL) Connector for ERPNext.

This app enables Singapore-based businesses to seamlessly transmit compliant UBL XML invoices over the IMDA PEPPOL network directly from ERPNext.

Note: This application is a specialized fork and structural adaptation of the excellent open-source myinvois framework built by ERPGulf for Malaysia's LHDN system, re-engineered specifically for Singapore's UEN and tax landscape.
